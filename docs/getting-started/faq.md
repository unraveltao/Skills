# FAQ

## Does the website execute or install Skills?

No. The website is a static catalog. Installation and execution occur in the user's compatible Agent client.

## Are the Skills fully verified?

Not automatically. Structural review, isolated tests, and real-Agent behavior acceptance are distinct; consult the dated [Skill Readiness](/Skills/docs/development/skill-readiness/) document.

## What if a Skill has no README?

Read its mandatory `SKILL.md` and referenced files. README files are optional.

## Does the npx command work for every Skill?

It is an **unverified candidate** for this repository until an end-to-end installer test is performed.

## Does loading a Skill grant tool permission?

No. Client tool availability, permissions and runtime dependencies still apply.

## How do I contribute?

Start with the [repository](https://github.com/unraveltao/Skills), read its `AGENTS.md`, and review individual Skill constraints.
