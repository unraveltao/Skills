# Introduction

Unravel Skills is a curated, open-source collection of **independently installable Agent Skills**. It is not a marketplace or an Agent runtime. Each Skill ships its instructions and any required support files together.

## Discover and understand

Browse the [Skills catalog](/Skills/#explore) to compare Skills for development, learning, planning, and utilities. On a Skill's detail page, read its summary, its README when available, and the original `SKILL.md`.

## Install and use

Follow [Installation](/Skills/docs/getting-started/installation/) and [Using Skills](/Skills/docs/guides/using-skills/) for the safe starting workflow. Compatibility and trigger behavior depend on your Agent client and permissions.

## Project structure

The `skills/` directory contains distributable instructions; `web/` contains the Astro site; `docs/` contains shared project guides and technical documentation. See [Architecture](/Skills/docs/concepts/architecture/).

## Verification boundaries

Publishing a Skill is not proof of real-Agent behavior acceptance. Read the dated [Skill Readiness](/Skills/docs/development/skill-readiness/) review for what was actually checked.
