# Categories

| Folder | Signals and examples |
|---|---|
| 01-Software | Consumer application installers/portable apps; app name, publisher, source. |
| 02-Developer-Tools | SDK, compiler, runtime, CLI, IDE toolchain; e.g. Rust toolchain bundle. |
| 03-Source-Code | Git clone/export, GitHub source archive, examples; source URL/project name matters. |
| 04-Documents | PDF, Office documents, books, tutorials. |
| 05-AI-Assets | GGUF, safetensors, checkpoints, LoRA, datasets/model bundles. |
| 06-Others | Identified media and other recognized assets. |
| 99-Review | Unclear purpose, ambiguous archive, conflict, or insufficient evidence. |

`00-Inbox` is intake, not a final classification. Extension is one clue only. ZIP/7z requires corroborating name/source or safe listing; never extract or run contents. Add rules here with strong indicators, counterexamples, and a Review fallback.
